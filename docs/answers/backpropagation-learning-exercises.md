## 3. 第一关：标量、向量、矩阵与 shape

### 核心知识点

设：

```python
x  = np.array([x1, x2])             # (2,)
W1 = np.array([[...], [...]])        # (2, 3)
b1 = np.array([b11, b12, b13])      # (3,)
W2 = np.array([w21, w22, w23])       # (3,)
b2 = np.array(0.1)                   # 0 维数组
```

前向传播各变量的 shape 是：

| 变量 | 表达式 | shape |
|---|---|---|
| `x` | 输入 | `(2,)` |
| `W1` | 第一层权重 | `(2, 3)` |
| `b1` | 第一层偏置 | `(3,)` |
| `y1` | `x @ W1 + b1` | `(3,)` |
| `h` | `relu(y1)` | `(3,)` |
| `W2` | 第二层权重 | `(3,)` |
| `z` | `h @ W2 + b2` | 标量/0 维数组 |
| `y_pred` | `sigmoid(z)` | 标量/0 维数组 |
| `loss` | BCE | 标量/0 维数组 |

注意：数学上的“标量”在 NumPy 中可能是 Python `float`、NumPy 标量或 shape 为 `()` 的 0 维数组。

## 4. 第二关：NumPy 运算与数学运算

### 核心知识点

三种运算不能混淆：

```python
A * B              # 对应位置逐元素相乘
A @ B              # 矩阵乘法或向量点积
np.outer(a, b)      # 两个向量的外积
```

在当前网络中：

```python
z = h @ W2                  # 两个 (3,) 向量点积，结果是标量
d_W2 = d_z * h              # 标量乘向量，结果为 (3,)
d_h = d_z * W2              # 标量乘向量，结果为 (3,)
d_W1 = np.outer(x, d_y1)    # (2,) 与 (3,) 外积，结果为 (2, 3)
```

梯度必须与它对应的参数 shape 相同：

```text
d_W1.shape == W1.shape
d_b1.shape == b1.shape
d_W2.shape == W2.shape
d_b2 与 b2 都是标量
```

## 5. 第三关：局部导数与链式法则

### 核心知识点

“参数”表示训练时会更新，不表示每次求导时都要同时变化。对某个变量求偏导时，其他独立变量暂时视为常数。

若：

```text
z = h₁w₁ + h₂w₂ + h₃w₃ + b
```

则：

```text
∂z/∂h = w
∂z/∂w = h
∂z/∂b = 1
```

链式法则可以理解为：

```text
当前梯度 = 上游梯度 × 当前节点的局部导数
```

当前网络完整的反向路径是：

```text
dL/dy_pred
  × dy_pred/dz
  × dz/dh
  × dh/dy1
  × dy1/dW1
```

### 练习 7：区分求导对象

给定：

```text
z = h₁w₁ + h₂w₂ + h₃w₃ + b
```

分别写出：

1. `∂z/∂h₁`；
2. `∂z/∂w₁`；
3. `∂z/∂h`（向量形式）；
4. `∂z/∂w`（向量形式）；
5. `∂z/∂b`。

### 练习 8：计算图填空

补全下面每个局部导数：

```text
y1 = x @ W1 + b1
h = relu(y1)
z = h @ W2 + b2
y_pred = sigmoid(z)
L = -[y log(y_pred) + (1-y) log(1-y_pred)]
```

```text
∂L/∂y_pred = ?
∂y_pred/∂z = ?
∂z/∂W2 = ?
∂z/∂h = ?
∂h/∂y1 = ?
∂y1/∂b1 = ?
```

每项还要注明结果是标量、向量还是矩阵。

### 练习 9：推导化简结果

从下面两式出发：

```text
∂L/∂y_pred = -y/y_pred + (1-y)/(1-y_pred)
∂y_pred/∂z = y_pred(1-y_pred)
```

证明对于 sigmoid 加二元交叉熵：

```text
∂L/∂z = y_pred - y
```

要求分别取 `y=1` 和 `y=0` 验证，再进行代数化简。

## 8. 第六关：数值稳定性

### 核心知识点

直接计算：

```python
sigmoid = 1 / (1 + np.exp(-z))
loss = -(y*np.log(p) + (1-y)*np.log(1-p))
```

在普通数值下没有问题，但极端输入可能导致：

- `np.exp(...)` 溢出；
- `p` 舍入为 `0` 或 `1`；
- `np.log(0)` 得到负无穷；
- loss 产生 `inf` 或 `nan`。

教学阶段可先裁剪概率：

```python
p_safe = np.clip(p, 1e-12, 1 - 1e-12)
```

更稳定的方案是直接从 logit 计算 BCE：

```python
loss = np.logaddexp(0.0, z) - y * z
```

## 9. 第七关：梯度检查

### 核心知识点

解析梯度来自反向传播，数值梯度用有限差分近似：

```text
dL/dθ ≈ [L(θ+ε) - L(θ-ε)] / (2ε)
```

推荐使用相对误差：

```python
relative_error = abs(g_analytic - g_numeric) / max(
    1.0, abs(g_analytic), abs(g_numeric)
)
```

数值梯度只用于检查，不用于正常训练，因为它需要对每个参数进行额外前向传播。

### 练习 19：检查一个参数

选择 `W2[0]`，完成：

```python
eps = 1e-5

W2_plus = W2.copy()
W2_minus = W2.copy()
W2_plus[0] += eps
W2_minus[0] -= eps

g_numeric = (loss_plus - loss_minus) / (2 * eps)
```

将它与反向传播得到的 `d_W2[0]` 比较。

### 练习 7

```text
∂z/∂h₁ = w₁
∂z/∂w₁ = h₁
∂z/∂h = w
∂z/∂w = h
∂z/∂b = 1
```

### 练习 8

```text
∂L/∂y_pred = -y/y_pred + (1-y)/(1-y_pred)   标量
∂y_pred/∂z = y_pred(1-y_pred)                标量
∂z/∂W2 = h                                  向量 (3,)
∂z/∂h = W2                                  向量 (3,)
∂h/∂y1 = 1[y1 > 0]                          向量 (3,)
∂y1/∂b1 = 1                                 逐元素恒等映射
```

最后一项更严格地说，其 Jacobian 是 `3 × 3` 单位矩阵；反向传播中因此有 `d_b1 = d_y1`。

### 练习 9

由于 `y` 只取 0 或 1：

```text
y = 1:
dL/dy_pred = -1/y_pred
dL/dz = (-1/y_pred) × y_pred(1-y_pred)
       = y_pred - 1

y = 0:
dL/dy_pred = 1/(1-y_pred)
dL/dz = [1/(1-y_pred)] × y_pred(1-y_pred)
       = y_pred
```

合并即：

```text
d_z = y_pred - y
```
